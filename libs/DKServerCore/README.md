# DKServerCore

MMOServer의 네트워크, 패킷, 메모리 관리와 모니터링 기능을 제공하는 C++ 공통 라이브러리

## 개요

Windows 서버 프로젝트에서 공통으로 사용하는 기능을 정적 라이브러리로 제공

## 구조

- `NetworkLibrary`
  - IOCP 서버와 LAN 서버·클라이언트
  - 세션 및 네트워크 입출력 관리
  - Content 그룹 생성과 세션 이동 관리
  - 서버 시작 설정 구조체

- `Packet`
  - 패킷 직렬화와 역직렬화
  - 패킷 인코딩과 디코딩
  - 링버퍼와 패킷 큐
  - 락프리 큐와 메시지 큐

- `Memory`
  - 객체 재사용을 위한 메모리풀
  - 락프리 및 TLS 기반 오브젝트 풀

- `Monitoring`
  - 프로세스와 시스템 CPU 사용률 측정
  - 프로세스 메모리 및 시스템 상태 수집

- `Utils`
  - 설정 파일 파서
  - 성능 프로파일러
  - 크래시 덤프
  - 스핀락과 공통 정의

## 주요 구현
- IOCP 기반 비동기 네트워크 입출력
- 서버와 클라이언트 네트워크 클래스
- 세션 관리와 연결 종료 처리
- 패킷 직렬화, 인코딩 및 참조 카운트 관리
- 링버퍼와 락프리 큐
- 메모리풀을 통한 객체 재사용
- Content 그룹별 메시지 전달과 업데이트
- 프로세스 및 시스템 모니터링
- 프로파일링과 덤프 생성
