# MonitoringServer

로그인·게임·채팅 서버와 시스템의 상태 정보를 수집하여 저장하고 모니터링 클라이언트에 전달하는 C++ 서버

**개요**

각 서버가 전송한 CPU, 메모리, 세션 수와 처리량 등의 상태 정보를 서버 종류별로 관리한다.

서버용 연결과 모니터링 클라이언트용 연결을 분리하며, 수집한 최신 상태는 클라이언트에 주기적으로 전달하고 집계 데이터는 MySQL에 저장한다.

**구조**

`SSMonitoringServer`

- `LanLibrary`를 상속한 서버 상태 수집용 서버
- 로그인·게임·채팅 서버의 종류와 상태 데이터 관리
- 시스템 CPU, 메모리와 네트워크 사용량 수집
- 수집 데이터의 평균·최솟값·최댓값 집계
- 집계된 모니터링 데이터를 MySQL에 저장

`CSMonitoringServer`

- `NetLibrary`를 상속한 모니터링 클라이언트용 서버
- 세션 키를 통한 모니터링 클라이언트 인증
- 로그인·게임·채팅 서버와 시스템의 최신 상태 전달
- 인증되지 않은 세션의 Timeout 처리

`MonitoringData`

- 모니터링 값과 측정 시각 관리
- 서버별 최신 값과 집계 데이터 관리
- 로그인·게임·채팅 서버 및 시스템 데이터 구조 정의

`CommonProtocol`

- 서버와 모니터링 클라이언트의 패킷 정의
- 서버 종류와 모니터링 데이터 종류 정의

`MonitoringMain`

- 서버 상태 수집용 서버와 클라이언트용 서버 시작
- 설정 파일을 통한 클라이언트용 서버 실행 정보 로드
- 세션 수, 처리량과 연결 종료 통계 출력
